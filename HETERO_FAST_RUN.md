# Hetero Fast Run

This compact pipeline keeps the original external baselines, but switches truth generation and unified evaluation to real heterogeneous SI/SIR diffusion.

## Main idea

- Truth is generated by Monte Carlo diffusion on the full heterogeneous graph.
- Infection probability depends on relation type, node-type mismatch, topology, and attribute/semantic similarity.
- HCF-Net keeps the paper logic:
  - target-node topology view
  - cross-community semantic neighbor view
  - type-aware feature projection before encoding
  - late fusion between topology and semantic scores
- External baselines are reused through the existing scripts, then re-evaluated with the new heterogeneous truth.

## One-command run

```bash
python -m hetero_fast.run --datasets ACM DBLP Yelp --gpu 0 --with-sensitivity
```

If you already have baseline outputs and only want the new truth/evaluation:

```bash
python -m hetero_fast.run --datasets ACM DBLP Yelp --skip-external --gpu 0 --with-sensitivity
```

Fastest first-pass run:

```bash
python -m hetero_fast.run --datasets ACM DBLP Yelp --gpu 0 --with-sensitivity --truth-mc-runs 2
```

## Outputs

- `hetero_fast_results/<DATASET>_summary.json`
- `hetero_fast_results/<DATASET>_sir.png`
- `hetero_fast_results/<DATASET>_si.png`
- `hetero_fast_results/all_metrics.csv`
- `hetero_fast_results/truth_cache/*`
- `hetero_fast_results/sensitivity/*`

## Notes

- First run is slower because Monte Carlo truth is cached.
- Re-running without `--force-truth` reuses saved truth.
- Recommended on the A10 machine with CUDA-enabled PyTorch.
